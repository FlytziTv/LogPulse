# LogPulse

Plateforme personnelle d'agrégation de logs — en cours de développement.

## C'est quoi ?

LogPulse est un dashboard de logs self-hosted qui centralise les logs de plusieurs projets en un seul endroit, avec un streaming en temps réel.

## Statut

En cours de développement — pas prêt pour une utilisation en production.

## Stack technique

- **API** — Node.js + Express + Prisma
- **Base de données** — PostgreSQL (NeonDB)
- **Auth** — Better Auth
- **Frontend** — Next.js + Tailwind CSS
